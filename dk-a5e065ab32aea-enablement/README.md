# Agilex 5 FPGA E-Series 065A Premium Development Kit — HPS Enablement

Platform folder `dk-a5e065ab32aea-enablement` contains designs for the Agilex 5 FPGA
E-Series 065A Premium Development Kit DK-A5E065AB32AEA with the HPS Enablement Expansion
Board (OOBE daughter card).

Refer to the [Agilex 5 E-Series Premium Development Kit Baseline System Example Design](https://altera-fpga.github.io/latest/embedded-designs/agilex-5/e-series/premium/gsrd/ug-gsrd-agx5e-premium/) for Baseline System Example Design context.

## Designs

| Design | Description |
|--------|-------------|
| [baseline-a55](baseline-a55/README.md) | Baseline-A55 design; boots from Arm Cortex-A55 core 0 |
| [baseline-a76](baseline-a76/README.md) | Baseline-A76 design; boots from Arm Cortex-A76 core 2 |
| [baseline-a55-fpga-first](baseline-a55-fpga-first/README.md) | Baseline-A55 FPGA First design; FPGA configured before HPS release |
| [tsn-rgmii-hvio](tsn-rgmii-hvio/README.md) | TSN RGMII HVIO design; RGMII from FPGA HVIO for TSN |
