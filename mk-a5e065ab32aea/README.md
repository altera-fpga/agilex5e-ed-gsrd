# Agilex 5 FPGA E-Series 065A Modular Development Kit

Platform folder `mk-a5e065ab32aea` contains designs for the Agilex 5 FPGA
E-Series 065A Modular Development Kit MK-A5E065AB32AEA.

Refer to the [Agilex 5 E-Series Modular Development Kit Baseline System Example Design](https://altera-fpga.github.io/latest/embedded-designs/agilex-5/e-series/modular/gsrd/ug-gsrd-agx5e-modular/) for Baseline System Example Design context.
