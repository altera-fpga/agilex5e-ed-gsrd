# HPS Baremetal Hello World Example Design (OCRAM)

The HPS Baremetal Hello World Example Design showcases a minimal, bare-metal
application running on the Agilex 5 HPS. The program uses baseline-a55
as the hardware design and runs the following actions:

1. Initialize the UART (115200 baud) for console output
2. Initialize the clock manager
3. Initialize the GIC for interrupt handling
4. Print platform and version information
5. Continuously print a "Hello World" message once per second

This variant links against the **OCRAM** memory layout: the application is
linked to run from the HPS on-chip RAM (`BUILD_MODE=OCRAM`) rather than DDR.

# Build Steps

The expected output of the build process is `baremetal.elf`, `baremetal.bin`
and `baremetal.hex` (along with the `.dump` artifact generated by the build).
The `.bin` (raw binary) and `.hex` (Intel ihex) are the on-chip-RAM loadable
images; all are loaded onto the Agilex 5 HPS.

1. Enter the baseline-a55 folder

```bash
cd TOP_DIR/dk-a5e065ab32aea-enablement/baseline-a55
```

2. Build the baremetal application

```bash
make software-hps_baremetal_ocram-build-sw
```

`baremetal.elf`, `baremetal.bin` and `baremetal.hex` should appear under the
`software/hps_baremetal/baremetal_ocram` directory.

(Note: the make target runs `./software/hps_baremetal/baremetal_ocram/build.sh` and then copies `build/hps_baremetal.elf` to `baremetal.elf`, `build/hps_baremetal.bin` to `baremetal.bin`, and `build/hps_baremetal.hex` to `baremetal.hex`.)

3. (Optional) Install the binary into the enablement output tree

```bash
make software-hps_baremetal_ocram-install-sw
```

This step is only needed for the full baseline enablement/packaging flow; it
copies `baremetal.elf`, `baremetal.bin` and `baremetal.hex` into the shared
output tree (under the `software/hps_baremetal/baremetal_ocram/` subdirectory,
kept separate from the DDR variant) where downstream steps collect software
binaries. Skip it if you only need the artifacts locally.

4. Clean the build artifacts

```bash
make software-hps_baremetal_ocram-clean-sw
```

# Toolchain

The build requires an AArch64 GCC cross toolchain. `build.sh` accepts either
the `aarch64-none-linux-gnu` or `aarch64-none-elf` GCC. If neither is already
on your `PATH`, the script falls back to a repo-local vendored toolchain
(`gcc-arm/bin`) if present. The toolchain can be downloaded from the
[Arm GNU Toolchain downloads page](https://developer.arm.com/downloads/-/arm-gnu-toolchain-downloads).

You can point the build at a specific toolchain by exporting `TOOLCHAIN_BIN`
before building:

```bash
export TOOLCHAIN_BIN=/path/to/<toolchain>/bin
make software-hps_baremetal_ocram-build-sw
```

The cross-compile setup lives in the baremetal repo
(`cmake/bm_toolchain.cmake`) and is included before `project()`, so a single
CMake configure pass is sufficient. The baremetal library is fetched
automatically via CMake `FetchContent` during configuration.
