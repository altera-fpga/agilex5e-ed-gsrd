# Agilex 5 FPGA E-Series 065B Premium Development Kit — HPS NAND

Platform folder `dk-a5e065bb32aea-nand` contains designs for the Agilex 5 FPGA
E-Series 065B Premium Development Kit DK-A5E065BB32AEA with the HPS NAND daughter card.

Refer to the [Agilex 5 E-Series Premium Development Kit Baseline System Example Design](https://altera-fpga.github.io/latest/embedded-designs/agilex-5/e-series/premium/gsrd/ug-gsrd-agx5e-premium/) for Baseline System Example Design context.
